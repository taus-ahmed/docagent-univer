## Stage 1 — conservation, group headers, dense pages

### 1a — printed but not extracted · 9c43d77, c6d2888, 8a7a6b0
**Cause.** Nothing compared what a page prints at a structural position with
what the result holds, so a dropped total, row or group number was silent.
**Change.** `engine/conservation.py`: structural tokens (table-row cells,
group-header identifiers, totals, labelled field values; not furniture,
prose, form metadata, phones, address digits) are each held by a value
(money by value, identifiers by digits), named by an existing reason, or
named in a new attention reason per page. A figure glued to an unreadable
glyph is its own token. A value-less label takes the figures beside it on
neighbouring lines (the Total Deduction box is split over three engine
lines). Templated: a missing row/total on a table page is attention; money
outside the template's tables is a note; identifiers it does not ask for,
and the other columns of a record it did capture, are its choice.
**Cases.** utah_paystub_2 Total Deduction (named as a partly unreadable
figure); vendor numbers (now held, 1b); 1099-K amounts (already named by
Q11, counted as said); carson's Checks/withdrawals total (held); fidelity:
no missing amount is silent. `tests/test_s1a_conservation*.py`.
**Not fixed.** Extraction of what is named (that is recovery, live only).

### 1b — group headers · 5c07443
**Cause (job 138).** The model answered the group column with the vendor
NAME; `row_groups.apply` filled the column only when empty, so 0 of 31 vendor
numbers reached the sheet. **Change.** The page's group line is always
written, split into identifier and name columns; a model value that is part
of the line is replaced, one the line does not print is flagged. Names from
the page's own label (colon stripped), else a context name marked inferred
(amber header, never the values). Approved by the owner: two R1 contract
tests updated to the split. Synthetic vocabularies: vendor, customer code,
employee id, alphanumeric, no identifier.

### 1c — dense pages · 52b5ec5, df8de7f
A page is asked again when it prints more of the band's rows than the answer
holds and two or more of its row lines are under half held; the request
names the lost lines. Multi-form pages: a form the template lacks cannot be
recovered into it; conservation names its figures. **Not verified live.**

### 1e — job 138's 686 marks · e0ff352
All 686 carried ONE reason: "Low: Not found on the page as quoted". The
group column's value (the vendor name) is printed on the group line, not on
the row's own line, so every later row of a group failed grounding, and one
failed cell marks a row. Group-column values are now checked against the
group line. Reconstruction (job 131's rows in 138's answer shape): 59 Low
rows → 0. There were no false reasons other than this one.

## Stage 2 — organized layout for every text-layer PDF · fd3f47c, 09d37ce

Spec v2: `docs/ORGANIZED_LAYOUT_SPEC.md` rules 11–17. One commit for 2b–2e:
they are one function (`page_cells`) and its writer.

* Placement stays x/y only; a content stream drawn in three shuffled orders
  lays out identically (tested). Irregular forms keep each value beside its
  label.
* One header row per table: a heading, title or footer written on an
  earlier page is not written again; page numbers are not copied.
* Formatting from the page: bold/italic from the font, underline from the
  stroke drawn under a segment, a thick rule as a thick bottom border, a
  line centred on the page centred. No fills.
* One date format: every notation becomes a real date shown `mm/dd/yyyy`,
  day/month order from the document's own dates; an unsettled order stays
  text.
* Nothing printed is left out: a line of two or more figures is never prose,
  and `audit()` checks from the layout's own record that every figure of
  every kept segment reaches a cell — **0 lost on all 60 text-layer PDFs**
  (1099 9, bank 9, cheque 2, card 3, expense 4, financials 3, invoice 9, long
  docs 1, payslip 8, PO 4, receipt PDF 2, W-2 6; the 10 scans have no text
  layer).
* Found on the way: the page gutter was 4× the median gap, which on a page of
  one-word cells is a column gap; it is now measured on small gaps only.
* utah_paystub_2 still matches the partner's sheet (5 tests unchanged).
